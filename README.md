# Sonora, Together

A responsive family field guide for a December visit to Hermosillo, Sonora. It includes curated coast, outdoors, culture, and food ideas, an adaptable three-day plan, practical winter notes, category filters, and direct map links.

The site is plain HTML, CSS, and JavaScript and can be served directly from the repository root on GitHub Pages.

Verify current hours, conditions, and availability before visiting.
